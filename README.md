# Basic_NLP_from_scratch
Implemented a very basic NLP from scratch wihtout using any libraries for RNN or Word Embedding.
This is just for educational purposes demonstrating the knowledge of NLP and its concepts like Word Embeddings and RNN.
Future Work includes but is not limited to-
1.Improving the model with more neurons
2.Using n-grams instead of bi-grams
3.Increased input dataset
4.Fine Tuning pre-trained word embeddings with new contextual data for specific purposes
5.Developing a fine-tuned chatbot
